Employee Time Management System is a single-page web app that turns a console-based Java project into a clean, responsive interface. It has two roles.

HR Managers can add and edit employee records (department, job title, contact details, start date), approve or deny time off requests, set weekly shifts and days off, correct logged hours, and generate reports showing time worked per employee and a summary of leave requests for any date range.

Employees can log their daily work hours, request time off, view their schedule for any date range (approved leave replaces the shift automatically), and track the status of their requests.

Time is shown in hours and minutes, such as 7 h 45 min, and totals are calculated in whole minutes. Overlapping time entries and duplicate leave requests are blocked. The interface works on desktop and mobile and follows light or dark mode automatically.

Built with plain HTML, CSS and a web version of a console-based Java project, rebuilt in JavaScript, with no frameworks or build step. Data is saved in the visitor’s browser (localStorage), and the app opens with sample data so you can explore it right away.
